# Aman Gupta — Portfolio

My personal portfolio, built to showcase my projects, skills, and background as a full-stack developer.

**Live site:** [https://amangupta.thelabs.wtf/]
**Image:** ![image reference](image-1.png)

## Tech Stack
- **Frontend:** Vue 3, Bootstrap
- **Animation:** GSAP (ScrollTrigger, timelines)
- **Other:** HTML5 Canvas (custom animated background)

## Features

- Custom canvas-based animated space background — twinkling stars, drifting nebula clouds, occasional shooting stars
- Scroll-triggered section animations using GSAP + ScrollTrigger
- Fully responsive layout, including a slide-in mobile navigation menu
- Glassmorphism-style navbar with backdrop blur
- Grouped, animated skills section with category-based color coding
- Project cards in a scrollable container, pulling from a structured data source.


## Project Structure

```
src/
├── assets/          # images, global CSS
├── components/       # NavBar, Preloader, SpaceBackground, other Section components
├── router/            # Vue Router config
└── main.js
└── App.vue # starting point of the vue application

```
